# Unity Scripts

This directory contains Unity helper scripts used in the synthetic-data preparation workflow for this project.

## Contents

- `CameraCaptureAnnotator`: exports rendered images and Structured Scene Information (SSI) from configured Unity scenes.
- `Unity_ConstructionPitGeneratorPlugin`: generates configurable simulated construction-pit geometry.
- `Unity_ManholeGeneratorPlugin`: generates configurable simulated manholes and open-manhole scenarios.

See the README in each subdirectory for setup and usage details.

This release does not include a complete Unity project, third-party scene assets, generated datasets, or an end-to-end annotation or navigation system.
