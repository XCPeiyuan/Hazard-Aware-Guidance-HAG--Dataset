# Hazard-Aware Guidance (HAG) Dataset

This repository is the planned release page for the dataset and code package associated with the paper:

**MLLM-Assisted Dataset Construction for Hazard-Aware Guidance for Individuals with Visual Impairments**

## Model Weights

The merged Qwen2.5-VL-7B model fine-tuned on the mixed-source
Real-world + Unity-based (R+U) dataset is available on Hugging Face:

[HAG-Qwen2.5-VL-7B-RU](https://huggingface.co/xcyuan/HAG-Qwen2.5-VL-7B-RU)

The model weights are hosted on Hugging Face and are not included in this
GitHub repository.

## Status

The release package is currently under preparation. No dataset files are currently published in this repository.

The planned public release will be prepared after paper acceptance, subject to third-party dataset licenses, base-model license constraints, and privacy/consent screening for self-collected media.

## Planned Contents

- Unity-based synthetic images and annotations
- Structured annotation files
- Reviewed evaluation labels
- Prompt templates
- Annotation-generation scripts
- Evaluation scripts
- Parser and evaluation utilities
- Fine-tuned model artifact, subject to base-model license constraints

Third-party real-world images will not be redistributed. Where permitted, image identifiers and reviewed labels will be released.
