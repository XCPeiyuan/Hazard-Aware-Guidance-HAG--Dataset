- `inference_efficiency_analysis/`: earlier single-run latency results and feasibility notes. Use `repeated_workstation_latency/` for the revised latency results.
- `structured_field_evaluation_independently_annotated_subset/`: structured-field evaluation summaries.
- `offline_diagnostic_analysis_mixed_source_ru_test_set/`: mixed-source object-level diagnostic summaries.
