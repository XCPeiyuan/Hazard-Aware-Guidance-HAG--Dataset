# Results

This directory contains compact result summaries copied from selected
experiments. The files are included to make the public repository informative
before the full dataset package is released.

## Included Result Groups

- `compatibility_aware_walking_awareness_dataset_comparison/`: WAD comparison aggregate summaries and paper-material notes.
- `inference_efficiency_analysis/`: server and mobile latency summary files.
- `structured_field_evaluation_independently_annotated_subset/`: pre-audit structured-field evaluation summaries used for the paper
  table authority chain.
- `offline_diagnostic_analysis_mixed_source_ru_test_set/`: distance-aware analysis metrics, validation reports, and Fig. 8
  rerun summaries.

## Scope Limits

These files are not the full raw experiment outputs. They are compact summaries
selected for public staging. Raw model outputs, private annotations, and large
intermediate files are intentionally excluded.
