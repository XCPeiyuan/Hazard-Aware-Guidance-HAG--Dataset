# Dataset Distribution and Preprocessing

This directory preserves two original utilities that support dataset inspection
and preparation.

| Script | Role |
| --- | --- |
| `cooccurrence_matrix.py` | Computes image-level co-occurrence statistics and a heatmap for 3 categories. |
| `split_vip.py` | Splits a conversation-style training JSON file into English and Chinese three-line text lists. |

Neither script includes its input dataset. Use only data that can be legally
redistributed or that you are authorized to process.
